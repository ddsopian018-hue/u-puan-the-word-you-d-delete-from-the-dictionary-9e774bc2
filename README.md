## The word: irregardless

*Irregardless* is the only word in the dictionary whose entire existence is an argument. Half the English-speaking world insists it isn't a real word; the other half uses it anyway — and the dictionary, caught in the middle, lists it anyway. Deleting it ends the debate in one stroke: no word, no argument, no more correcting your uncle at dinner. The joke needs no setup because everyone has already had this fight, and the punchline is self-erasing — the word that shouldn't exist finally stops existing. "Moist" would only win the cringe vote everyone else is also submitting; "irregardless" is the fresher pick, and its humour comes from the word itself.

## Run it

```sh
python3 main.py
```

This writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).
